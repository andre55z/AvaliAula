# 📝AvaliAula

## 👋 Bem-vindo ao AvaliAula!
AvaliAula é um aplicativo desenvolvido com o objetivo de promover a melhoria contínua do ensino por meio da avaliação criteriosa e prática dos professores por parte dos alunos.

O sistema foi pensado para ser simples, direto e acessível, atendendo dois tipos principais de usuários:

## 🎓 Para Alunos
Os alunos podem acessar um formulário de avaliação para dar feedback sobre as aulas de seus professores. As avaliações são feitas com base em critérios específicos:

-> Clareza

-> Didática

-> Material utilizado

-> Interação com os alunos

Além disso, os alunos devem informar o nome do professor e da disciplina, podendo adicionar comentários opcionais com sugestões ou observações adicionais. O envio é anônimo.

## 👨‍🏫 Para Professores
Os professores têm acesso a uma área de visualização de feedbacks, onde podem:

Filtrar os feedbacks recebidos pelo próprio nome

Visualizar médias de avaliação para cada critério

Ler os comentários deixados pelos alunos

Esse painel visa fornecer uma visão clara sobre o desempenho do docente a partir da perspectiva dos alunos, incentivando melhorias contínuas no processo de ensino-aprendizagem.

## ⚙️ Funcionalidades
### 📄 Formulário de avaliação para alunos

### 📊 Listagem de feedbacks com filtro por professor

### 📈 Cálculo de médias por critério

### 🔍 Filtros por nome e disciplina

### 🔀 Navegação entre rotas com React Router
